# C5: Serving schemas and the validator in the Postgres dialect

Capstone batch 1, step 5. Contract: `docs/capstone/design.md` §5.

Build:
1. `src/governor/core/serving.py` with a CLI `python -m governor.core.serving apply --source <schema> --policy <file> [--access <file>]` (admin DSN from env `GOVERNOR_PG_ADMIN_DSN`, salt from env `GOVERNOR_PII_SALT`):
   - stores the salt in `private.pii_salt` (one row; replaced on each apply);
   - for every table in the source schema creates `serve_analyst.<table>` and `serve_finance_admin.<table>` views. analyst: each PII column from the policy becomes the salted SHA-256 hex digest from design §5, reading the salt from `private.pii_salt` inside the view; finance_admin: each PII column becomes the access file's mask value unless the access file grants that column; other columns pass through unchanged;
   - grants each reader role USAGE and SELECT on its own serving schema only; revokes everything else from `PUBLIC` on these schemas;
   - is idempotent (drop and recreate the views) and prints one JSON summary line.
   The salt value must never appear in a view definition.
2. The validator runs in the Postgres dialect through the adapter: schema-qualified relations on the allowlist, no `SELECT *`, no wall-clock functions, one statement, SELECT/WITH only, LIMIT injected or capped. Tests use their own access and policy fixtures in `tests/`; do not create files under `knowledge/` (the shop's policy and access files are human-owned and written after this step).
3. Validator tests (offline, with their own fixtures) named `test_validator_postgres_rejects_select_star`, `test_validator_postgres_injects_limit` and `test_validator_postgres_default_deny`.
4. Tests in `tests/testbed/` (skip without the DSNs): hashing keeps equality and `COUNT(DISTINCT ...)`, the mask applies, grants are honoured, each reader role is denied the other role's schema, `private` and `raw`.

Read: `src/governor/ask/{validator,policy}.py`, `src/governor/core/adapters/`, `knowledge/access.yaml` and `knowledge/policy.yaml` (format only), `docs/capstone/design.md` §5.

Done when `plan/accept/accept_c5.py` passes; Docker Desktop must be running.
