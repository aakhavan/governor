# G7: API, authentication and deployment skeleton

governor-ask becomes a service. Every client (Streamlit in G8, MCP in G9, curl) goes through one API; the caller's role comes from a server-side token, never from the request.

Build:
1. `src/governor/ask/service.py`: `ask(question, role, thread_id=None) -> AskResult`, `resume(thread_id, answer, role) -> AskResult`, `list_traces(role, outcome=None, limit=50)`, `get_trace(trace_id, role)`, `settings()`. `AskResult{status: answered|clarify|refused|unanswerable|error, answer, result_columns, result_rows, clarify_question, sql, models, lineage, freshness, cost_usd, trace_id, thread_id}`. The graph is compiled once per process. A thread or trace is visible only to the role that created it.
2. `src/governor/api/__init__.py`, `src/governor/api/app.py`: FastAPI app `governor.api.app:app` with exactly:
   - `GET /health` (no auth): `{status, as_of, version}`;
   - `POST /v1/ask` body `{question, thread_id?}` (pydantic, `extra="forbid"`, so a `role` field is a 422);
   - `POST /v1/threads/{thread_id}/resume` body `{answer}`;
   - `GET /v1/traces?outcome=&limit=` and `GET /v1/traces/{trace_id}`.
   - Auth: `Authorization: Bearer <token>`. Tokens come from env `GOVERNOR_API_TOKENS`, format `role:token,role:token`, compared with `hmac.compare_digest`; missing or unknown token is 401; a role not in `access.yaml` at startup is a startup error. Never log tokens.
   - Errors return `{error, code}` JSON without stack traces; refusals never echo the question.
   - `GOVERNOR_LLM=fake` uses `governor.ask.llm_testing` (tests, demos without a key).
3. `Dockerfile` (python:3.12-slim + uv): installs the project, then at build time runs `fixture/build_green.py`, the harvester and `python -m governor.ask.catalog build`, so the image carries a read-only warehouse; runs `uvicorn governor.api.app:app` on port 8000 as a non-root user; state in `/data` via `GOVERNOR_STATE_DIR`.
4. `docker-compose.yml`: services `api` (8000) and `ui` (Streamlit, 8501, filled in G8), a named volume for `/data`, env from a `.env` file that is never committed (provide `.env.example` with placeholder values only).
5. `docs/deploy.md`: local run (uvicorn and compose), the token format, the state volume, and a short comparison of single-container hosts (a VM, Fly.io, Render, Cloud Run with a volume). The choice waits for the capstone brief. State plainly that this is a single-tenant portfolio deployment.
6. Tests in `tests/api/` with FastAPI `TestClient` and `GOVERNOR_LLM=fake`, exact names: `test_health_needs_no_token`, `test_ask_requires_token`, `test_role_comes_from_token`, `test_role_in_body_rejected`, `test_ask_and_resume_clarify`, `test_traces_scoped_to_role`, `test_errors_have_no_traceback`.

Add `fastapi`, `uvicorn` and `httpx` to `pyproject.toml` (reason in NOTES).
