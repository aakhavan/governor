# E3: Perturbed test bed for one holdout run

Capstone batch 2d. Contract: `docs/capstone/batch2d.md` section 24 (design.md section 4 for the test bed).

Build:
1. `testbed/perturb.py` (stdlib only, deterministic): renamed tables and columns from a fixed mapping in the script, reversed column order, the orders table split into header and delivery, the junk table `etl_audit_log`, `mapping.json` and the renamed `policy.yaml`. Values and row order are never touched. It validates its input with the same header check as `testbed/load_olist.py` (import `EXPECTED` from it; do not copy the list).
2. `testbed/load_csv_dir.py`: generic loader into `raw` (text columns plus `_loaded_at`, one transaction per table, identifiers composed with `psycopg.sql`), `--replace` drops every table in `raw` first and is required when `raw` holds tables; one JSON line of row counts. Never touches another schema.
3. `src/governor/eval/build_eval.py`: `--policy <file>`, passed into the existing hooks; without it nothing changes.
4. `testbed/README.md`: the "Perturbed holdout" section with the commands and the run-once rule, and the licence note of section 24 in place of the TODO.

Tests (offline; on `testbed/sample/` in a temp folder):
- `tests/testbed/test_perturb.py`: `test_perturb_is_deterministic`, `test_no_original_table_or_column_name_survives`, `test_values_and_row_counts_are_unchanged` (map the perturbed files back through `mapping.json` and compare cell by cell with the sample), `test_orders_split_keeps_every_order`, `test_policy_is_renamed_through_the_mapping`, `test_junk_table_is_written`;
- `tests/testbed/test_load_csv_dir.py`: `test_loader_refuses_a_non_empty_raw_without_replace` and `test_loader_builds_safe_statements` without a database (test the statement-building and the guard as functions); a live round trip may be added but must skip unless the acceptance test bed variables are set;
- `tests/eval/`: `test_build_eval_policy_option_reaches_the_hooks` and that the default is still the shop policy.

Read: `docs/capstone/batch2d.md` section 24, `testbed/load_olist.py`, `testbed/README.md`, `testbed/sample/` (headers only), `knowledge/shop/policy.yaml`, `src/governor/eval/build_eval.py` (the hooks dataclass and `main`), `tests/eval/test_build_eval.py`.

Do not change `testbed/load_olist.py`, `evaluation/`, `knowledge/` or anything under `src/governor/build/`. Never read or copy `testbed/data/`.

Done when `plan/accept/accept_e3.py` passes.
