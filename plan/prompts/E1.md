# E1: Certified answers in Slack (`/governor ask`)

Capstone batch 2d. Contract: `docs/capstone/batch2d.md` section 22 (batch2c sections 17, 20 and 21 still hold).

Build:
1. `src/governor/integrations/slack/config.py`: `GOVERNOR_SLACK_ASK_ROLE` (default `analyst`, must be a certified reader role), `GOVERNOR_SLACK_ASKERS` (ids, `*`, or unset = the runners), `GOVERNOR_SLACK_ASK_LLM` (default `openrouter`); `is_asker(user_id)`.
2. `src/governor/integrations/slack/app.py`: `ask <question>` in `parse_command` (the whole remainder is the question, 3 to 300 characters); `GovernorSlack` gets an injectable `asker` callable `(question, role) -> CertifiedAnswer`, whose default imports `governor.ask.certified` inside the function and calls `certified.answer(question, role, certified.make_llm(<ask llm>))`; `handle_command` acknowledges, then runs the ask in the runner.
3. `src/governor/integrations/slack/blocks.py`: the usage line for `ask`; a pure function that renders the channel message (question escaped for Slack on one line, the answer text unchanged, the context line); refusal and error texts.
4. Replies as in section 22: `answer`, `not_available` and `unanswerable` go to the channel; `refused` and errors are ephemeral to the asker and never repeat the question; errors pass through `safe_text`. Log outcome, KPI id and user id only.
5. `docs/slack.md`: the command, the three settings, and that the app process needs the ask login.

Tests (`tests/integrations/test_slack_ask.py`, fake Slack client, inline runner, a fake `asker`; no database, no network):
`test_ask_parses_the_whole_question`, `test_ask_needs_a_question_of_sane_length`, `test_ask_posts_the_certified_answer_in_the_channel`, `test_ask_not_available_shows_the_gap_text`, `test_ask_refusal_is_ephemeral_without_the_question`, `test_ask_error_is_scrubbed_and_ephemeral`, `test_ask_requires_an_asker`, `test_ask_role_comes_from_config_only`, `test_ask_role_must_be_a_reader_role`.

Read: `docs/capstone/batch2d.md` section 22, `src/governor/integrations/slack/{app,config,blocks}.py`, `src/governor/ask/certified.py` (only `CertifiedAnswer`, `READER_ROLES`, `answer`, `make_llm`, `CertifiedError`), `tests/integrations/conftest.py`, `docs/slack.md`.

Do not change `governor.ask` or `governor.build` in this step.
