# V1: Run-event contract, reducer and build-graph tracing

Batch 4. Contract: `docs/capstone/batch4.md` sections 33–35. Decision: `docs/adr/0005-run-console.md`.

Rules for the whole batch (contract §33): no behaviour change when the console is unused, no data values in anything new (counts, names, codes, statuses, durations, tokens, cost only), build and ask never import each other or integrations, code owns every edge, `evaluation/` and `knowledge/` untouched, existing tests unchanged, tests offline.

Build:
1. Package `src/governor/core/runtrace/`: `RunLog` (writer, §34, never raises, `GOVERNOR_RUNTRACE=0` turns it off, seq continues across processes), `traced(graph, node_id, fn, summarise)` (keeps the node signature and return value; `GraphInterrupt` emits `run_paused` and re-raises; other exceptions emit `node_failed` with the class name only), a context variable for the run id when a node has no `config`, `fold(events)` (§34 reducer), and `registry` with `NodeSpec`, the build graph's node specs and edge labels, and `topology("build")` (§35).
2. `src/governor/build/graph.py`: wrap every node in `build_graph` with `traced` and a summariser per node (§35 table; counts, names and codes only, ≤ 80 chars; never the approver's name); emit `run_started` / `run_finished` in `start`, and `run_resumed` / `run_finished` in `_resume` (`run_finished` only when the thread ended, with the final status and totals). Metrics come from the `calls` the node's update adds. Do not change edges, state or the existing `emit(...)` build events.
3. `tests/fixtures/console/fold_cases.json`: the 8 shared cases of §34 (empty, straight, repair attempt 2, pause→resume→finish, failed node, duplicate + out-of-order seq, up-to-date skip, unknown cost) as `[{"name", "events", "expected"}]`. `expected` is the exact `fold()` output, JSON-serialisable (V4's TypeScript reducer must match it field for field, so keep the shape simple: `{run: {...}, nodes: {id: {...}}}`).

Tests:
- `tests/core/`: `test_runlog_appends_and_continues_seq`, `test_runlog_never_raises`, `test_runtrace_off_writes_nothing`, `test_fold_cases` (parametrised over fold_cases.json), `test_traced_keeps_return_value`, `test_interrupt_is_pause_not_failure`, `test_failure_records_class_name_only`
- `tests/build/`: `test_build_registry_matches_graph`, `test_build_conditional_edges_labelled`, `test_build_run_log_full_run` (offline full build with the existing fakes: run_started … design_gate paused … resumed … run_finished; attempts and summaries present), `test_build_run_log_has_no_data_values` (a marker string in the fake profile's sample values never appears in the log), `test_build_events_unchanged` (events.jsonl kinds for a run are the same with tracing on and off)
