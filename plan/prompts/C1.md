# C1: Close the four open follow-ups from the G phase

Capstone batch 1, step 1 (`docs/capstone/design.md` §2). These four were left open after G10b. Fix them without changing ask's behaviour or prompts.

Build:
1. **Checkpoint privacy.** With `GOVERNOR_TRACE_TEXT` unset, the LangGraph checkpoint store must not keep the raw question or any result rows once a run has finished. Delete a thread's checkpoints when its run ends (answered, refused or unanswerable). Keep them only while a run is paused at `clarify`, and delete paused threads older than `GOVERNOR_THREAD_TTL_H` hours (default 24) at the start of the next ask. Apply this in both the API service (`src/governor/ask/service.py`) and the CLI (`src/governor/ask/run.py`). Deleted data must not stay in the database file: SQLite keeps deleted pages, so enable `secure_delete` (or vacuum) on the checkpoint connection. Write in NOTES which LangGraph checkpointer API you used and what it guarantees.
2. **OpenAPI.** `/openapi.json` returns 404 unless `GOVERNOR_API_DOCS=1` (`docs_url` is already off). Read the variable when the app is created.
3. **Dry-run timeout.** `executor.dry_run(sql, *, timeout_s, ...)` is interrupted exactly like `run_readonly` (same timer helper, raises `QueryTimeout`); `execute()` passes the access.yaml timeout to it.
4. **Deploy check.** The Docker image still builds and runs as a non-root user. Update `docs/deploy.md` only where these fixes change a step or a variable.
