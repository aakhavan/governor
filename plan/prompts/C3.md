# C3: Postgres test bed with the Olist loader and a synthetic sample

Capstone batch 1, step 3. Contract: `docs/capstone/design.md` §4 (compose file, schemas, loader, sample, expected headers).

Build:
1. `testbed/docker-compose.yml`: Postgres 16, host port 55432, named volume, healthcheck, database `shop`, admin user `governor_admin`, password `${GOVERNOR_PG_PASSWORD:-governor_local}`.
2. `testbed/load_olist.py --source <dir> [--dsn <dsn>]` (DSN defaults to env `GOVERNOR_PG_DSN`): checks that all 9 expected files exist with exactly the expected headers (fail with a clear message naming the file and the difference), creates schema `raw` if missing, loads each CSV into `raw.<file stem>` with all columns as text plus `_loaded_at timestamptz`, using COPY, truncate and load in one transaction per table, and prints one JSON line `{"table": rows, ...}`. Typing happens later in silver, not here.
3. `testbed/sample/`: the 9 CSVs with the exact headers, at most 30 rows each, obviously synthetic values, and every edge case listed in design §4.
4. `testbed/README.md`: what the test bed is; how to start and stop it; how to get the real Olist dataset into `testbed/data/` (manual download from the dataset's Kaggle page; licence note to be filled in after the licence check, leave a clearly marked TODO); how to load it.
5. `.gitignore`: `testbed/data/`.
6. Add `psycopg[binary]` to the dependencies (reason in NOTES).
7. Tests in `tests/testbed/`: `test_headers_validated` (a wrong header fails clearly, offline) and `test_sample_edge_cases_present` (offline, reads the CSVs). Database tests skip when `GOVERNOR_PG_DSN` is unset.

Read: `docs/capstone/design.md` §4.

Done when `plan/accept/accept_c3.py` passes. It starts the compose stack under its own project name and removes it afterwards; Docker Desktop must be running.
