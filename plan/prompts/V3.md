# V3: Console API (SSE, replay, artifacts), demo runs and LangGraph Studio entry points

Batch 4. Contract: `docs/capstone/batch4.md` section 36 (events §34, topology §35).

Rules for the whole batch (contract §33): no behaviour change when the console is unused, no data values in anything new (counts, names, codes, statuses, durations, tokens, cost only), build and ask never import each other or integrations, code owns every edge, `evaluation/` and `knowledge/` untouched, existing tests unchanged, tests offline.

Build:
1. `src/governor/integrations/console/`: a FastAPI `APIRouter` (`make_console_router(caller_role)`) with the five read-only routes of §36, auth as §36 (token, or `GOVERNOR_CONSOLE_OPEN=1`), CORS for `GOVERNOR_CONSOLE_ORIGINS` (applied so the existing routes are not opened). Run discovery reads `GOVERNOR_STATE_DIR/runs/<graph>/*.jsonl` (`source: live`) and the shipped demo folder (`source: demo`); a run id found in both prefers live. SSE: `StreamingResponse` with `text/event-stream`, frames `id/event/data`, `Last-Event-ID`, heartbeat comments, live tail (≤ 0.5 s poll) ending on `run_finished` or 30 min idle, replay pacing = original gap ÷ speed capped at 2 s, `speed` clamped to 1–32. Make the clock and sleep injectable so tests run in milliseconds.
2. Artifacts (§36): names and counts only, from the target's `governor/build.json`, `governor/design.json` and dbt `target/manifest.json` when present; the target comes from the run's `run_started` event (add a `target_name` field there only if needed — never a full path in the response). Missing inputs give empty lists and nulls.
3. `src/governor/api/app.py`: mount the router under `/v1/console`. Nothing else in the app changes.
4. `scripts/make_console_demo.py`: drives the **real traced graphs** with the test fakes (fake LLM, fake dbt runner, synthetic sample) and a fixed clock; writes the four demo runs of §36 plus build artifacts into `src/governor/integrations/console/demo/`. Deterministic: two runs give identical files. Commit the generated demo files.
5. LangGraph Studio: `src/governor/integrations/studio.py` with `build()` and `ask()` returning compiled graphs without a checkpointer (real OpenRouter LLM when `OPENROUTER_API_KEY` is set, else the fake; no network at import), and `langgraph.json` as in §36.

Tests:
- `tests/api/`: `test_console_requires_token`, `test_console_open_mode_allows_reads_only`, `test_console_graph_topology`, `test_console_runs_lists_live_and_demo`, `test_console_run_view_matches_fold`, `test_console_sse_frames_and_last_event_id`, `test_console_replay_pacing_capped`, `test_console_live_tail_ends_on_run_finished`, `test_console_artifacts_names_and_counts_only`, `test_console_artifacts_missing_inputs`, `test_ask_routes_unchanged_with_console`
- `tests/integrations/`: `test_demo_runs_deterministic`, `test_demo_runs_cover_required_cases`, `test_studio_graphs_compile_offline`
